## 🧪 研究効率化ツールの開発
**React + TypeScript 版**

---

## 📘 Overview
本ツールは、**研究実験の効率化**を目的に開発したWebアプリケーションです。  
従来、手作業で行っていた実験準備・データ提示などの工程を自動化することで、  
研究作業の効率を大幅に向上させました。

当初は **JavaScript** で構築していましたが、後に **React + TypeScript** による再構築を行い、  
状態管理やコンポーネント設計を意識したモダンなフロントエンド開発を実践しました。

---

## 💡 Learning & Highlights
- React Router を用いた段階的な画面遷移の設計  
- useState / useEffect による状態制御の理解深化  
- 研究の身近な課題をweb技術で解決

---

## 🚀 Features
- 実験手順の自動化：画像提示・評価入力/出力などをWeb上で完結  
- 動的な条件管理：React Hooksによる状態管理で柔軟に制御可能  
- 再利用性の高い設計：UIをコンポーネント単位で整理  
- TypeScript導入：型定義によりコードの可読性・保守性を向上

## 🧱 Page Structure
- `/` ：実験概要・説明ページ  
- `/consent` ：同意画面  
- `/experiment` ：実験トップページ（条件リンク一覧）  
- `/image/:id` ：画像提示ページ  
- `/evaluation/:id` ：評価入力ページ  
- `/finish` ：完了画面
